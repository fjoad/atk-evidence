# Turn Ritual

Classify each request before acting.

| Tier | Signal | Ritual |
|---|---|---|
| Trivial | Typo or single metadata correction | Execute and verify |
| Small | Bounded, well-understood change | State approach, implement, verify |
| Medium | Multi-file code or experiment change | Written plan, tests, verification, finish |
| Major | New paper, evidence contract, or architecture | Written plan with checkpoint, user approval, implementation, verification, finish |

For ambiguity, classify one tier higher. If the user says to skip rituals or
invokes `/charter-off`, execute directly for that session. Scientific
pre-registration and evidence-integrity constraints still apply.
