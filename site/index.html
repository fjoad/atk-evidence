ATK Evidence

We rebuild the experiments in published papers whose results we doubt, run them, and compare our numbers with the published ones.

Many machine-learning papers don't publish their code. They do describe their method, and that should be enough for another researcher to rebuild it. So that is what we do: we write the code the paper describes, fill any gaps the way a reasonable researcher would, run the experiment and compare.

We start from doubt, but we try to test it fairly. When our rebuild matches the paper, we say so. When it doesn't, we check our own work first, then ask whether any reasonable version of the method could reach the published numbers. How we work
